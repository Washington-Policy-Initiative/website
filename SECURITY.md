# Security policy

## Reporting a security issue

If you find a security problem with the Washington Policy Initiative website (<https://wapolicyinitiative.org>) or this repository, please report it privately. **Don't open a public GitHub issue, pull request, or discussion**, since that would make the problem visible before it's fixed.

Email **washingtonpolicyinitiative@gmail.com** with:

- a short description of the issue and where it occurs (page, URL, or file)
- the steps needed to reproduce it
- what you think the impact is

We'll acknowledge your report as soon as we can, keep you updated while we look into it, and let you know when it's resolved. Please give us a reasonable amount of time to fix the issue before sharing it with anyone else.

## Scope

In scope: this website and the code in this repository, including the CMS login functions in `functions/api/`.

Out of scope: third-party services the site relies on (such as GitHub, Cloudflare, LinkedIn, or Instagram). Please report problems with those to the service directly.

Please don't access other people's data, degrade the site for other visitors, or use automated scanning that sends large amounts of traffic.
